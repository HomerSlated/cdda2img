BIN file format
===============
The .bin file contains raw CD-DA audio in disc-native byte order (s16be).
Sample rate: 44100 Hz, stereo (2 channels), 16-bit signed integer.
Byte order: big-endian (s16be) — byte-swapped from the s16le stored in the RBI.

To burn with cdrdao:
  cdrdao write --device /dev/sr0 <stem>.toc

The .toc file references the .bin by name; both must be in the same directory.
